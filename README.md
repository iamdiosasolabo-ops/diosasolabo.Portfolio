# DiosaSolabo.com — GitHub Pages

A faithful visual recreation of the supplied Canva portfolio PDF. The portfolio is displayed as optimized section images to preserve the original design, with clickable discovery-call links.

## Publish
1. Create a public GitHub repository named `YOURUSERNAME.github.io` (replace YOURUSERNAME).
2. Upload `index.html`, `CNAME`, and the entire `assets` folder to the repository root.
3. In Settings > Pages, select Deploy from branch > main > /(root).
4. In Settings > Pages, set custom domain to `diosasolabo.com`.
5. In Namecheap Advanced DNS, set four A records for @ to 185.199.108.153, 185.199.109.153, 185.199.110.153, 185.199.111.153 and a CNAME for www to YOURUSERNAME.github.io. Keep any email records.
6. Wait for DNS to propagate, then enable Enforce HTTPS.
